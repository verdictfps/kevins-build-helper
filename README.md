# Kevin's Build Helper
Build Calculator webapp for the game SULFUR (https://store.steampowered.com/app/2124120/SULFUR/)

Access it here: https://verdictfps.github.io/kevins-build-helper/

No need to clone, this will update automatically.

## Features

* Built-in randomizers - no more waffling on that last enchantment

* Highly responsive item search system - search by category, name, percentage, and more

* Filters and sorting - sort alphabetically or by positive (or negative) trait amount, and filter by primary categories

* Extraordinarily detailed stat breakdowns - every single in-game stat (and many that don't exist in the game at all!) is displayed and updated in real time, both on items in dropdowns and in the Build Card

* Extended stats - breakdown of custom stats for the number junkies, including DPS, Damage Before Breaking, and a custom Recoil-to-RPM Score

* Hover over EVERYTHING to get more info about it in the Infobox - even the stats themselves!

* Store and clone up to five builds at once to compare stats, create loadouts, or design challenges

* An intricate assortment of buttons to cater to your every need

* Enable and disable components on the fly

* Screenshotting built-in! Use the Copy Screenshot or Save Screenshot buttons above the weapon image window to nab a screenshot of your Build Card and paste (or post) wherever you like

* Unique links for every build - use the Copy button above the weapon image window or copy directly from the address bar to share a direct link of your build, and opening a link loads the build itself; pasting a link into the box allows builds to be loaded directly into the current session

* Easter eggs! Good luck :D
